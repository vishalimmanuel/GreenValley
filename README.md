# Greenvalley Matriculation High School website

A simple multi-page website for Greenvalley Matriculation High School, built with plain HTML and CSS.

Live site: https://vishalimmanuel.in

## Pages
- `home.html` / `index.html`: welcome and school introduction
- `admission.html`: admissions information for 2025-2026
- `classinfo.html`: class pages from Kindergarten onwards
- `gallery.html`: school photo gallery

## Tech
Static HTML and CSS with no build step, hosted on GitHub Pages with a custom domain (see `CNAME`).

## Run locally
Open `index.html` in a browser.
